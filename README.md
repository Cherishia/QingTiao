# 轻跳 0.5.35

Android 8 及以上；画面识别需 Android 11 及以上。min API 26，compile/target API 36。

## 清理后重连与桌面快捷方式（0.5.35）

无障碍系统开关仍开启时，系统重新连接轻跳后会立即重新核验前台并恢复处理。启用「清理后恢复提醒」后，发现系统开关已关闭会提供恢复入口；开关仍开启但服务断连时先等系统重连，再安排一次延后核验。排除应用流程主动停用时暂停提醒。

添加桌面快捷方式时显示请求是否送达，收到系统固定完成的回执后才报告添加成功。还会尝试给轻跳图标的长按菜单添加最近选择的「停用」入口。

## 排除应用的桌面快捷方式（0.5.34）

从「不处理的应用」选择对应软件，可以创建「停用」桌面快捷方式。点新图标会等待系统稳定确认轻跳的无障碍已关闭，再打开目标应用。如果当次需要停用轻跳，会重新从应用入口启动，清掉旧页面任务。系统无法在限定时间内确认时，会进入无障碍设置，返回后再核对状态。用完需要在系统设置手动重新启用轻跳。

## 点击前复查、停用入口和抓取记录（0.5.33）

绘制广告面板的两个确认帧现在同时跟踪关闭按钮与广告标识的位置。附近有播放页标签时，当前控件树的广告标识与画面位置一致、且有独立的内嵌和底部观看入口，可以补充复查证据。关闭按钮同一行的普通面板标题、敏感控件、冲突窗口和过期画面仍会阻止点击。抓取记录会说明具体的取消条件。

排除应用的「停用并打开」会核对系统配置、当前启用列表和服务连接状态，再打开应用。必要时先进入系统设置等用户关闭权限。无障碍关闭提醒需用户开启，在系统允许时低频检查状态，点通知进入系统设置。用于排除应用的主动停用会暂停提醒。

首页最近记录只保留「抓取记录」入口，直接打开自动生成的广告识别记录。

## 通用绘制广告面板与首页（0.5.32）

网页或绘制容器所在页面可以保留普通文字、同时省略广告按钮的无障碍标签。出现这种情况时，轻跳在界面事件触发下有限取帧。关闭前，两张同一前台窗口的新画面都要找到独立广告字样、卡片边缘和右上关闭图形，并通过当前界面复查。普通评论、分享和设置面板的原生标题会阻止触摸。

首页自动记录界面识别结果，合并常用开关，保留广告识别记录和运行诊断两个入口。排除列表显示应用名和图标；如应用要求关闭无障碍，可从排除列表主动停用轻跳服务后打开该应用，用完后在系统设置重新开启。

## B 站视频广告与主页（0.5.31）

支持「前往观看」位于内嵌视频简介、广告标识位于其下方的面板。若控件树提供了两个标签却缺少可用位置，两张画面都必须另行核验左侧广告小字、卡片边缘和右上关闭图形。截图次数继续使用当前窗口的有限额度。

主页集中显示无障碍状态、常用开关、动作统计、应用排除和最近动作。可选的摇一摇返回只在有当前广告证据时短暂监听加速度计。动作后振动和摇一摇返回默认关闭。

## B站绘制广告面板（0.5.30）

B 站当前窗口只有无文字控件时，可在有限画面探测中识别底部广告面板。两张同窗口的新画面须同时匹配右上 X、三点菜单、拖动条、标题栏及下方卡片边缘旁的「广告」两字。触摸前再确认当前前台窗口与控件树，动作记录会显示「BILI_DRAWN_AD_CONFIRMED」。

## B站灰色暂停广告卡片（0.5.29）

当 B 站暂停广告没有暴露「前往观看」或关闭描述时，当前广告标识与唯一右上触控区域可以启动最多两次的本地画面核验。触控区域必须位于窄右侧标题栏内，分享、关注、箭头和菜单控件不适用。画面还要同时匹配右上 X、左侧三点、顶部拖动条和标题栏对比，第二张新画面及最终当前控件树复查通过后才触摸 X。

该路径适配深色与灰色卡片。截图失败、面板消失或窗口变化会结束本次识别。它不扩大截图预算，也不在普通视频页持续读取画面。

## 长时间运行时的调度与复查（0.5.29）

手机无截图能力时，跳过视觉探测计划，原生控件路径继续按事件运行。已排定的开屏时点在普通内容事件合并后继续有效。视觉动作的结果观察限制在原应用、原窗口和 3 秒内，窗口变化、取图失败或读到不同页面时结束。WM 的独立补点时限和两帧要求保持。

B 站曾尝试关闭的暂停面板首次消失时，只补一次同窗口控件树确认。后一条广告在冷却期出现时，可在冷却结束后用当前证据重新识别。截图失败时可使用该面板剩下的原有名额。标题栏的原生关闭按钮遇到「前往观看」等冲突语义会被排除。

运行诊断显示本次服务的完整控件扫描和截图请求次数。同应用不同窗口的历史动作单独标注。用真机画面确认广告关闭，并在相同使用条件下比较 CPU 时间和延迟。

## 已出现全屏广告的快速复查（0.5.27）

通用开屏首轮画面未识别到跳过按钮、但当前控件树已核验全屏广告容器时，可将最后一个未用的常规开屏截图名额提前一次。取图前仍重新核验窗口及容器；提前取图与上一请求至少相隔 350ms，受同一全局限速约束。普通开屏间隔、总名额及两帧确认保持。提前复查未命中时，仍保留下一常规槽，受正常截图间隔限制；原最后槽已移到较早时点。

## 开屏探测到点执行（0.5.26）

没有原生跳过按钮时，已有额度的开屏探测按到期时间直接进入同一个扫描队列。它不再借用一秒兜底或普通扫描间隔，窗口事件仍可提前唤醒。首次出现已核验的全屏广告容器时，即使窗口切换用完额外名额，也能提前使用一个还未用到的常规槽。常规与额外名额总数、全局截图限额、同窗口两张新帧确认、空闲观察与锁屏停扫不变。

诊断的「扫描调度」区分「开屏探测到点直达」与普通扫描，可查看实际超过计划的毫秒数。识别在手机本机完成；未做实际设备时延或耗电测量。

## 通用开屏与 B 站暂停广告（0.5.25）

开屏优先处理语义明确的原生按钮。规则按实际全屏广告布局、广告标识或明确广告图片及按钮角色组合核验，可跨应用复用。按钮须唯一、位于当前广告分支，刷新后仍可见、可点击且语义一致；普通「跳过」、滚动区域、敏感页面及证据冲突不能凭坐标补判。没有可用控件时继续支持图形识别，并覆盖有独立广告证据的右下纯「跳过」深色按钮。

B 站暂停广告优先使用当前广告区域内明确的关闭控件；画面回退只在有当前广告上下文时启动，要求关闭 X、三点、拖动条和最后一次面板归属复查。无可靠原生边界时，须有独立广告标识和「前往观看」分处两个控件，以及两张新画面。面板标题为评论、分享或设置等普通操作时拒绝。每次出现的面板只分配两到三次发现取图，已有候选的第二帧继续使用原有间隔和限额；动画或按钮位置波动不会续期。

通用开屏只使用已有的常规及额外探测槽，有证据时把一次探测提前，不把「广告」文字变成连续取图的开关。开屏处理后结束静默启动观察，浏览广告仍由界面事件触发。原 JM 计时、WM/OOPZ 专用安全路径、30 秒空闲窗口观察、锁屏停扫和用户设置保留。

## 减少确认等待与简化诊断（0.5.24）

JM 仍按页面要求等待三秒，使用原 3100ms 保护时长。确认红 X 后，稳定场景只需一次中途核验及一次到点的新画面。操作前仍需当前红 X 和完整页面复查，线路仍由用户选。触摸提交后结束本次计时，后续画面只用于观察结果。

B 站面板、B 站纯画面开屏和通用绘制按钮，在首帧已匹配时，可先只核验当前应用、窗口、屏幕及尺寸后取第二帧。点击前仍重读完整控件树，保持两张同源新帧、目标类型和截图及点击限额。窗口变化和明确线索仍可要求完整扫描；WM/OOPZ 专用流程保持原有确认方式。

「诊断与记录」移除三项模拟自检，保留运行诊断、广告识别记录、点击记录、采集下一次开屏与功能开关。历史识别数据和功能设置保留。

## 原生开屏优先与浅色 B 站画面（0.5.23）

用户的 B 站记录已读到右下“跳过 0”、count_down 及 splash_layout / splash_button_container / splash_interact_view，但 0.5.22 的原生计时规则只覆盖右上，转而等待有限截图探测；画面则因浅色视频把白色 UI 与背景连在一起而反复失败。本版补通原生路径，并按真实浅色截图修复回退。

新增 NativeSplashSkip 布局族，不按 B 站包名单独放行：当前宿主命名空间下的完整全屏 splash_layout、同分支全屏 splash_button_container、大面积 splash_interact_view，以及唯一、启用、可点击的右下 count_down，文字严格为“跳过＋一至两位数字”，全部成立才成为原生候选。拒绝隐藏、禁用、错误宿主、资源名子串、小区域、分支不一致、重复按钮、滚动祖先、敏感/输入/图片预览等场景。仍经完整当前树、目标刷新和真实前台窗口复查，禁止父节点动作；当前原生控件可处理时不等两帧或截图计划。控件动作未接受时按现有设置尝试该目标手势，复查次数有限。系统接受原生开屏动作后停止该次启动的盲目画面探测，后续广告面板仍可处理。

明确“跳过/广告/模式提醒”文字事件进入原有 30ms 优先调度，继续受 120ms 最小扫描间隔与事件合并约束；普通页面/滚动仍采用原省电间隔。实际窗口变更在事件无包名时也能要求完整重读。未增加后台轮询、启动截图额度或每分钟动作/画面额度。

浅色画面回退保留左下平台字标、独立向上箭头、右下逐字跳过、单个后缀数字及深色胶囊全部证据和两帧确认：

- 字标用既有 UI 参考，并在原阈值之外补 220 亮度分量，区分浅背景与白色字形，字形相似度不放宽。
- 箭头除原连通形状外，支持同一小区域内两个堆叠的完整亮度轮廓，每个轮廓都必须亮于两侧背景；没有删除箭头要求或靠照片内容匹配。
- 原数字后缀搜索越过胶囊右侧，会把浅色广告内容算成额外笔画。回退只核验允许的数字范围，并在数字处再次确认胶囊上下边界，保留唯一性与字形门限。原 OOPZ 页头数字规则未改。

3202 项构建检查通过，新增 114 项原生布局与浅色 UI 反例。新/旧 B 站开屏及六张反例合计 253 项回放、两张旧面板 154 项、旧通用绘制 208 项及上一版真实括号秒数 173 项均通过（各回放包含相应基础检查，不相加为独立项）。没有增加权限、线程、唤醒锁或保活服务；没有重置设置、移除两帧确认或跳过最终敏感页面校验。没有手机实测时延和电量，不能承诺每条广告在一秒内关闭。

用户第二条面板记录在 01:32:44 已提交并完成对 X 的触摸，后续到桌面导致复查取消；它不能证明关闭失败或成功。01:32:46 的 1049ms 遍历属于后续采样，也不能直接算成之前的触摸等待。本版明确区分原生开屏与画面面板动作，继续按实际结果记录，不把系统接受手势当成广告关闭。

## 全屏广告图片与括号秒数（0.5.22）

本次已按用户提供的真实截图核验“跳过(1s)”右上胶囊。0.5.21 没有把全屏 ImageView 的 iv_advertisement_image 资源识别为独立广告证据，且原来的独立两字规则会拒绝相邻括号秒数；这两个漏点都需要处理。

新增通用广告图片资源模式：ImageView 类、资源短名为 advertisement / advertisement_image / advertisement_img，可带 iv_ / img_ / image_ 前缀，并沿用当前可见、启用、不可编辑/勾选/滚动及全屏覆盖门限。资源名须整体匹配，设置、预览、复制、普通 ad_image 和仅包名含 advertisement 均不成立。没有给完美世界电竞增加包名分支。该证据只允许进入字形核验，不能凭 ID 直接点击，触摸前仍重新读取当前完整页面。

复用右上两字搜索，支持当前“跳过＋左括号＋单个数字轮廓＋s＋右括号”深色胶囊。完整括号秒数布局要求逐字分数至少 84%；原独立两字仍需至少 90%。新增局部亮度分割以覆盖彩色半透明背景，检查括号弯曲方向、独立数字/单位的尺寸及基线、空白边距、胶囊上下边界与唯一位置。不是通用 OCR，不支持所有字体、颜色或多位秒数。

修复另一条通用分隔线规则把数字 1 的中间亮笔画当作竖线的问题：在完整亮度轮廓中确认分隔线仍为直窄矩形，不能只看中性白色碎片。删除括号时不会绕过完整倒计时结构进入这条规则。原 OOPZ 专用入口及其点击保护保持。

省电调度不变：新后缀检查仅在当前广告证据成立且当前两字有匹配分数后处理很小的局部区域，复用同一次截图和搜索；没有增加常规截图次数、后台轮询、线程、权限、唤醒锁或保活。发现与两帧确认仍分开，已找到目标按原 350ms 最短间隔请求第二张新画面。根读取本次耗时 528ms 是系统读取部分，没有把它算成字形匹配耗时或承诺固定加速比例。

完整构建 3088 项通过（原 3027 项及新增 61 项），真实截图与局部删改回放 173 项通过（含 61 项基础检查）。四种源尺寸使用双线性/双三次重采样，宽于 720 时按生产路径再缩小，全部定位到右上“过”字内部；删除任一字、任一括号、数字或 s 后拒绝。去掉当前独立广告证据、缺少胶囊、非唯一目标、敏感/图片预览上下文均拒绝。旧通用绘制开屏及 B 站回归另行执行。

本次有真实截图回放，没有连接手机测量自动触摸后的广告关闭、识别时延或电池消耗。不能将截图定位通过或系统报告手势完成当作已在真机关闭广告；厂商智能限制结束服务时仍不能保证后台继续运行。

## 通用无倒计时跳过与重复读取优化（0.5.21）

新增右上角独立“跳过”两字图形规则，不要求旁边有数字；复用通用广告路径，不按完美世界电竞的包名判断。仍需当前可见广告文字/标识、明确覆盖全屏的广告容器，或既有双色图标及“广告”两字徽标之一作为独立广告证据。新规则逐字匹配、拒绝左右相邻文字、歧义位置，并要求同应用/窗口/屏幕/尺寸的两张独立新画面。不能只凭右上有“跳过”就操作引导页、输入页或图片。

明确全屏广告容器须当前可见、可用、不可编辑/勾选/滚动，覆盖至少 80% 宽、70% 高及 65% 屏幕面积，并有明确 splash_ad / startup_ad / SDK splash 资源 ID 或 SplashAdView 等广告类型。普通 splash 启动页、广告设置页、列表中的小广告均不能证明。最终触摸前重新检查当前完整页面及广告证据；WM 禁止原生/父节点动作的保护不变。

速度与功耗优化：

- Android 13 及以上不再使用不可中断的强制批量预取。按首子分支/兄弟节点分批读取，保留完整遍历，不按隐藏节点或固定节点数裁剪页面。Android 8–12 继续使用原接口。
- 在同一真实窗口、显示屏及尺寸下，无新线索的重复发现遍历合并：启动前 6 秒，完整读取后至少留 350ms 间隔；之后至少 1000ms。仍读取当前根和窗口元数据。新根归属、实际窗口/尺寸变化、明确跳过/广告/模式提醒事件、当前动作复查及已找到目标的两帧确认均优先，不沿用缓存目标操作。
- 新出现的明确全屏广告容器可共享原来最多两次额外发现机会，尽快检查同窗口迟到的广告；与新窗口机会共享额度，没有增加六次常规加两次额外的总预算。
- 修复无原生标签的通用目标已匹配后，第二帧还被稀疏发现计划挡住的问题；已找到目标的确认继续按 350ms 最短间隔，不等待几秒后的下一次无证据探测。
- 圆圈识别复用相同的圆周三角函数值，形状/字形阈值不变。截图/动作总限额、600ms 帧新鲜度、30 秒空闲兜底、熄屏停扫、设置与模式提醒保持。
