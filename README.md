# 轻跳 0.5.35

Android 8 及以上；画面识别需 Android 11 及以上。min API 26，compile/target API 36。

## 模式提醒弹窗

保留“关闭青少年／未成年人模式提醒”，默认开启，入口在“诊断与记录 → 功能开关”。依赖“模拟手指点击”，不重置其他开关。只关闭介绍提醒，不改变已经开启的模式，也不点击开启、退出、年龄声明、验证或监护设置。

要求当前同一有限弹窗内同时出现明确模式标题、未成年人保护/健康成长介绍及唯一中性按钮；支持“我知道了、知道了、暂不开启、暂不启用、暂不设置、以后再说、稍后再说”及相应繁体字。只按文字和当前结构判断，不依赖特定应用包名。按钮文字须属于独立可交互按钮，嵌套标签可定位文字内部，但不调用父节点动作。无文字 X、纯图片、笼统确定/取消及不完整上下文均不猜测。

行动前重新读取真实窗口、尺寸及整段提醒结构，确认同一按钮后只触摸文字内部。当前实现仅在默认显示屏处理；不调用原生按钮/父节点、不增加提醒补点；持续存在的同一目标受既有防重复及每分钟总动作预算限制。提醒盖住广告时暂停旧目标证明，不触摸后面的广告。

复用现有事件与控件遍历，不新增截图、定时任务、常驻线程、联网或权限。没有可信关闭按钮时进入事件等待，不为提醒开启持续图形检测。已有广告识别、省电间隔、熄屏暂停、两帧和有限补点策略保留。没有对应真机样本，控件树模拟通过不代表所有应用弹窗都已适配。

## 默认省电策略

本版默认启用事件优先省电调度，不增加用户开关，不关闭已有识别功能或改写原设置。

- 熄屏、锁屏、暂停时停止定时读取，同时把无障碍界面事件订阅设为零，避免继续接收普通内容更新。收到亮屏/解锁、功能设置变化或系统重新连接后恢复订阅，重新核验真实前台；不沿用旧窗口或点击证明。
- 普通空闲页面每 30 秒只兜底读取归属，原为 6 秒；普通内容更新合并为至少 1500ms，滚动更新 2500ms。应用切换和窗口事件可提前唤醒；已确认广告继续使用 120ms 扫描下限。
- 未命中目标的启动内容不再被每个事件持续加速；早期内容以 300ms 合并、450ms 下限处理，无证据连续复查至少 700ms。稀疏图形探测仍保留 0、0.7、2、5、11、22 秒计划及最多两次新窗口机会，等待下一时点时不按秒重复读取。活跃观察直接进入一次真实根核验，省去先读根再排队重读根的过程。
- 静止且未定位目标的画面，只在同宿主、窗口、显示屏、源尺寸、代次及检测上下文中短暂复用失败结果。比较整张分析图的两个 64 位散列，不保留像素；任一变化即重新分析，最迟 1 秒强制重新分析。只缓存失败结果，不缓存目标，不用于两帧确认。SDK、原生独立标签、志愿汇、哔咔、JM、B 站、正在确认/复查的任务不走此缓存。截图本身仍需新取，不宣称省掉这些截图。
- 普通诊断更新留在内存，历史序列化与写盘合并为 10 秒；切换前台、取消、动作关键记录会及时保存。突然杀进程可能损失最后不足 10 秒的普通诊断；不影响动作判定。首页只在可见时每 5 秒刷新状态，内容不变时不重复设置文字。

## 跳过机制与取舍

打开诊断页时按需读取最新内存记录，不必等 10 秒写盘。历史访问与更新同步保护，省去普通后台循环中的反复完整编码。

保留通用“数字｜跳过 / 跳过｜数字”、深浅色水印、完整 WM SDK 控件、OOPZ 左上/左下菜单、有限来源承载窗口、JM 手动选线、哔咔公告/X、志愿汇、驾考宝典和 B 站规则。没有新增仅按 OOPZ 包名识别的省电例外。

找到目标后的第二帧最少 350ms、普通截图最少 450ms、画面不超过 600ms、每分钟最多 60 张及 8 次动作等限制保留。WM 仍需当前 SDK 和两帧、80/100ms 短触、至少 1800ms、固定 20 秒且最多两次。真实窗口、当前页面、敏感/输入/图库排除等最终复查不省略；不改成盲点、旧坐标或父节点点击。

省电减少的是无证据时的工作，不承诺所有场景速度完全不变：普通内容扫描的等待更长，如果系统完全漏掉事件，30 秒归属兜底可能来不及处理短广告。不能同时保证极少轮询与漏事件时仍即时响应。现有功能和识别条件保留，不等于保证所有广告均能关闭。

## 智能限制后台运行

可尝试使用系统智能限制，但本版不能保证该模式下始终运行。小米官方说明智能省电可能释放资源或结束进程：https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1628 。没有存活的服务就无法响应广告；亮屏恢复和系统重连恢复均以系统实际交付回调为前提。

这台设备此前已在智能限制下跳过失效，重视稳定性时仍建议轻跳设为“无限制”并允许自启动，让应用内部调度控制耗电。“无限制”是执行许可，不代表程序会持续占用 CPU。本版不增加前台保活服务、定时闹钟、唤醒锁、联网轮询或反复自启动。

## 构建

Python 3、JDK 17、Android SDK Platform 36 和兼容 Build Tools：

```powershell
python build.py --java-home '你的JDK目录' --build-tools '你的SDK/build-tools/35.0.0' --android-jar '你的SDK/platforms/android-36/android.jar' --out './QingTiao-0.5.29.apk'
```

可用 --build-dir 指定中间目录。同一签名覆盖安装需在本地使用原 signing/local-test.p12。源码归档省略签名密钥，首次从归档构建时脚本会生成新签名。
