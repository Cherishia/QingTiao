# 轻跳

轻跳是一款 Android 应用，利用无障碍服务识别并尝试关闭支持的开屏广告、浏览弹窗和视频广告面板。支持 **Android 8 及以上**，画面识别需要 **Android 11 及以上**。

[下载最新版 APK](https://github.com/Cherishia/QingTiao/releases/latest) · [查看所有版本](https://github.com/Cherishia/QingTiao/releases)

## 开始使用

1. 在发布页的 **Assets** 中下载 `QingTiao-版本号.apk`，安装后打开轻跳。
2. 点「无障碍设置」，启用「轻跳 · 跳过开屏广告」，再确认首页的「自动跳过广告」已开启。
3. 需要处理浏览中的广告时，开启「处理浏览广告」。漏跳时可以在首页点「抓取记录」，查看轻跳识别到了什么。
4. 点首页底部版本号旁的「检查更新」。发现新版时会自动下载并校验 APK，然后打开系统安装界面。首次更新时按 Android 提示开启轻跳的安装权限，再确认安装。

## 常用功能

- **开屏和弹窗识别**。优先使用可核验的原生控件；部分绘制广告可通过本机画面识别。点击前会复查当前前台窗口和目标。
- **模式介绍提醒**。只在标题、介绍和中性关闭按钮都匹配时关闭提醒，例如「我知道了」。轻跳不会操作年龄验证、监护设置或模式开关。
- **摇一摇跳转返回**。可选。只有发现当前广告证据时才短暂监听摇动，并且只在符合条件的浏览器或商店跳转上尝试返回。
- **不处理的应用**。可以跳过指定应用。对于要求停用无障碍的应用，可使用「停用并重开」或添加带「停用」字样的桌面快捷方式；用完后在系统无障碍设置重新启用轻跳。
- **清理后恢复提醒**。系统重新连接轻跳后，轻跳会重新检查前台。开启提醒后，长时间未重连或无障碍开关被关闭时可以收到通知。系统开关被关闭后需要手动重新启用。

## 省电与记录

识别以界面事件为主，锁屏后暂停处理。画面按需在手机本机内存中分析，抓取记录保存的是诊断摘要，不保存或上传截图。如果一段时间后频繁漏跳，可检查无障碍服务状态和手机给轻跳设置的后台运行限制。

## 从源码构建

需要 **Python 3、JDK 17、Android SDK Platform 36** 和兼容的 **Android Build Tools**（例如 35.0.0）。在仓库根目录执行，替换为本机路径。

```powershell
python build.py --java-home 'C:/path/to/jdk-17' --build-tools 'C:/path/to/Android/Sdk/build-tools/35.0.0' --android-jar 'C:/path/to/Android/Sdk/platforms/android-36/android.jar' --out './QingTiao-0.5.40.apk'
```

构建脚本会先跑测试，再编译并签名。可用 `--build-dir` 指定中间目录。首次从公开源码构建会生成本地测试签名；覆盖安装 GitHub 上的正式发布包，请使用同一发布签名的 APK。

发布更新时使用与 `versionName` 一致的 Git 标签（如 `v0.5.40`），递增 `versionCode`，并将用原证书签名的 `QingTiao-版本号.apk` 加入该正式 Release。
